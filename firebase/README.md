# BCN — বরাটি কেবল নেটওয়ার্ক (Firebase সংস্করণ)

বাড়ি বাড়ি ওয়াইফাই দেওয়ার হাতে-লেখা হিসাব ডিজিটাল করার ওয়েব অ্যাপ — Firebase সংস্করণ।
পুরো বাংলা ভাষায়। কোনো নিজের সার্ভার লাগে না: Firestore-ই ডেটাবেস, Firebase Hosting-ই ওয়েবসাইট।

## নিয়ম — এগুলো বদলানো যাবে না

- শুধু ওয়াইফাই কাস্টমার। ডিশলাইন বাদ।
- সবার বিল একই: **৫০০ টাকা / মাস**।
- ১২ মাসের কার্ড **যেদিন লাইন দেবে, সেদিন থেকে** গুনবে — জানুয়ারি-ডিসেম্বর না।
- মাসের হিসাব আসল ক্যালেন্ডার ধরে: ৩০ দিনের মাস, ৩১ দিনের মাস, ফেব্রুয়ারি ২৮ দিন (লিপ ইয়ারে ২৯ দিন)। ৩০ দিন যোগ করে হিসাব করা যাবে না।
- যেমন ১০ নভেম্বর লাইন দিলে ১ম মাস ১০ নভেম্বর–৯ ডিসেম্বর, ২য় মাস ১০ ডিসেম্বর–৯ জানুয়ারি।
- ৩১ তারিখে লাইন দিলে ফেব্রুয়ারিতে ওই মাসের শেষ দিনে শেষ হবে, মার্চে আবার ৩১ তারিখে ফিরবে।

## অ্যাপে যা আছে

- **লগইন:** প্রথমে মালিকের ইমেইল/পাসওয়ার্ড দিয়ে লগইন করতে হয়। লগইন ছাড়া কেউ কিছু দেখতে পারবে না।
- **হোম:** চলতি মাসে কত আদায়, কার বাকি — প্রত্যেকের চলতি মাস তার লাইন দেওয়ার তারিখ ধরে গোনা হয়।
- **কাস্টমার তালিকা:** নাম/মোবাইল দিয়ে খোঁজা ও ফিল্টার (বিল বাকি / বিল দিয়েছে / লাইন চালু / লাইন বন্ধ), শুধু ওয়াইফাই।
- **১২ মাসের কার্ড:** প্রত্যেক কাস্টমারের কার্ড — ঘরে চাপ দিলেই বিলের টিক পড়ে (৫০০ টাকা), আবার চাপ দিলে টিক উঠে যায়।
- **খাতা:** বকেয়া তালিকা (মেয়াদ শেষের তারিখ অনুযায়ী সাজানো) আর সাম্প্রতিক আদায়ের হিসাব।
- **রাউটার:** WiFi নাম-পাসওয়ার্ড, কোম্পানি/মডেল, IP, PPPoE, ONU — এক জায়গায়; লাইন চালু/বন্ধ সুইচ; **“রাউটারে ঢুকুন”** বোতাম — ওই বাড়ির ওয়াইফাইয়ে যুক্ত থাকলে চাপ দিলেই ব্রাউজারে রাউটার IP খুলবে, IP লিখতে হবে না। IP না থাকলে বোতাম দেখাবে না।
- **অফলাইন:** নেট না থাকলেও অ্যাপ চলবে — বিলের টিক ফোনে জমা থাকবে, নেট এলে নিজে থেকে Firestore-এ চলে যাবে।

## সীমাবদ্ধতা — সত্যি করে

অ্যাপের লাইন চালু/বন্ধ সুইচ এখন খাতায় লাইনের অবস্থা বদলায়। রাউটারে দূর থেকে সত্যি সত্যি
লাইন বন্ধ করতে MikroTik / রাউটার API সংযোগ লাগবে, সেটা এই সংস্করণে নেই।

## Firebase প্রজেক্ট

- প্রজেক্ট: `bcn-barati-cable-network` (Firebase Console-এ “BCN Barati Cable Network”)
- Firestore: Standard edition, লোকেশন `asia-south1` (মুম্বাই)
- কালেকশন: `customers`, `payments`
- ফ্রি (Spark) প্ল্যান: দিনে ৫০,০০০ বার পড়া, ২০,০০০ বার লেখা, ১ GB জমা — ৩৫০ জন কাস্টমারের জন্য অনেক বেশি, আজীবন ফ্রি চলবে।

## প্রথমবার চালু করার ধাপ (একবারই করতে হবে)

Firebase Console-এ (console.firebase.google.com) মাইশার Gmail দিয়ে লগইন করে:

### ১. মালিকের লগইন বানানো
1. বাম মেনুতে **Build → Authentication** খুলুন।
2. **Sign-in method** ট্যাবে গিয়ে **Email/Password** চালু করুন (Enable → Save)।
3. **Users** ট্যাবে গিয়ে **Add user** চাপুন — মালিকের ইমেইল আর একটা শক্ত পাসওয়ার্ড দিন।
4. এই ইমেইল-পাসওয়ার্ড দিয়েই অ্যাপে লগইন করতে হবে। পাসওয়ার্ড কাউকে চ্যাটে লিখে পাঠাবেন না।

### ২. Firestore চালু আছে কি না দেখা
1. বাম মেনুতে **Build → Firestore Database** খুলুন।
2. ডেটাবেস না থাকলে **Create database** চাপুন → **Standard edition** → লোকেশন `asia-south1` → **Start in production mode**।

### ৩. নিরাপত্তার নিয়ম (Rules) দেওয়া
1. Firestore Database-এর **Rules** ট্যাবে যান।
2. এই ফোল্ডারের `firestore.rules` ফাইলের পুরো লেখাটা কপি করে ওখানে বসান।
3. **Publish** চাপুন।
4. এই নিয়মে শুধু লগইন করা মালিকই পড়তে ও লিখতে পারবে — লগইন ছাড়া কেউ কিছু দেখতে পারবে না।

## ডিপ্লয় করা (ওয়েবসাইট লাইভ করা)

ল্যাপটপে একবারই:

```bash
npm install -g firebase-tools
firebase login
cd barati-cable-network-firebase
npm install
npm run build
firebase deploy
```

`firebase deploy` শেষ হলে একটা লিংক দেবে — যেমন
`https://bcn-barati-cable-network.web.app` — ওই লিংকেই BCN চলবে।
এরপর কোড বদলালে শুধু `npm run build` আর `firebase deploy` করলেই হবে।

## লোকালে চালানো (টেস্ট করার জন্য)

```bash
npm install
npm run dev
```

ব্রাউজারে `http://localhost:5173` খুলুন।

## ফাইলের হিসাব

- `src/App.tsx` — পুরো UI (হোম, কাস্টমার, কার্ড, খাতা, রাউটার, লগইন)
- `src/lib/firebase.ts` — Firebase চালু করা + অফলাইন ক্যাশ (IndexedDB)
- `src/lib/firebaseConfig.ts` — প্রজেক্টের কনফিগ (BCN প্রজেক্টের)
- `src/lib/store.ts` — Firestore থেকে পড়া/লেখা (customers, payments)
- `src/lib/bangla.ts` — বাংলা সংখ্যা/তারিখ আর আসল ক্যালেন্ডারের হিসাব
- `firestore.rules` — নিরাপত্তার নিয়ম (শুধু লগইন করা মালিক)
- `firebase.json` — Hosting সেটিং (build করা `dist` ফোল্ডার দেখাবে)
