# বরাটি কেবল নেটওয়ার্ক

বাড়ি বাড়ি ডিশলাইন ওয়াইফাই দেওয়ার হাতে-লেখা হিসাব ডিজিটাল করার ওয়েব অ্যাপ। পুরো বাংলা ভাষায়।

## নিয়ম — এগুলো বদলানো যাবে না

- শুধু ওয়াইফাই কাস্টমার। ডিশলাইন বাদ।
- সবার বিল একই: **৫০০ টাকা / মাস**।
- ১২ মাসের কার্ড **যেদিন লাইন দেবে, সেদিন থেকে** গুনবে — জানুয়ারি-ডিসেম্বর না।
- মাসের হিসাব আসল ক্যালেন্ডার ধরে: ৩০ দিনের মাস, ৩১ দিনের মাস, ফেব্রুয়ারি ২৮ দিন (লিপ ইয়ারে ২৯ দিন)। ৩০ দিন যোগ করে হিসাব করা যাবে না।
- যেমন ১০ নভেম্বর লাইন দিলে ১ম মাস ১০ নভেম্বর–৯ ডিসেম্বর, ২য় মাস ১০ ডিসেম্বর–৯ জানুয়ারি।
- ৩১ তারিখে লাইন দিলে ফেব্রুয়ারিতে ওই মাসের শেষ দিনে শেষ হবে, মার্চে আবার ৩১ তারিখে ফিরবে।

## অ্যাপে যা আছে

- হোম: চলতি মাসে কত আদায়, কার বাকি
- কাস্টমার তালিকা: খোঁজা ও ফিল্টার, শুধু ওয়াইফাই
- প্রত্যেক কাস্টমারের ১২ মাসের ডিজিটাল কার্ড — ঘরে চাপ দিলেই বিলের টিক পড়ে
- খাতা: বকেয়া তালিকা আর সাম্প্রতিক আদায়ের হিসাব
- রাউটারের তথ্য: WiFi নাম-পাসওয়ার্ড, মডেল, IP, PPPoE, ONU — এক জায়গায়
- লাইন চালু/বন্ধ সুইচ — খাতায় লাইনের অবস্থা বদলায়

## সীমাবদ্ধতা — সত্যি করে

অ্যাপের লাইন চালু/বন্ধ সুইচ এখন খাতায় লাইনের অবস্থা বদলায়। রাউটারে দূর থেকে সত্যি সত্যি
লাইন বন্ধ করতে MikroTik / রাউটার API সংযোগ লাগবে, সেটা এই সংস্করণে নেই।

## কোড

- `client/src/` — React ক্লায়েন্ট (App.tsx-তে কার্ড, খাতা, রাউটার UI)
- `server/src/` — সার্ভার অ্যাকশন (`actions.ts`) ও স্কিমা (`schema.ts`)
- `drizzle/` — ডাটাবেস মাইগ্রেশন (customers, payments)
- `package.json` — Bun প্রজেক্ট

এই কোড Muse-এর Space রানটাইমে চলে (`@hatch/space-sdk` ফাইল-নির্ভরতা)।
বাইরে সাধারণ সার্ভারে চালাতে হলে Space রানটাইমের বদলে নিজের ব্যাকএন্ড লাগবে।

## চালানো

Muse-এর ভেতরে অ্যাপটি খুললেই চলবে — আলাদা করে ইনস্টল করতে হয় না।
কোড বদলাতে চাইলে Muse-কে বললেই সে অ্যাপে বদলে দেবে, তারপর এখানে পুশ করবে।
